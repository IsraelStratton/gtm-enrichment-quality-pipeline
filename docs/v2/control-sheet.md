# Control sheet (draft)

Draft started in chapter 3. The full one-page sheet, laid out on the six practices of Australia's Guidance for AI Adoption, is finished in the wrap (KB-137, A1.5). This draft holds the part that exists now: every connection the build uses and what it can reach. Chapter 2 added the Claude key in n8n, the run-log login, the read-only playbook folder and the routing form; the routing agent has its own role card in [role-cards/routing-agent.md](role-cards/routing-agent.md). Chapter 4 added the Salesforce login (an API-only integration user through an External Client App) and the Salesforce routing form. Chapter 5 added the quote desk's own Salesforce login (a second API-only user, through a second External Client App), a new use of the Google login (staff messages to the build account's own inbox), the desk's form, and the admin CLI login used once to seed the made-up quotes; its four agents have role cards in [role-cards/quote-desk-agents.md](role-cards/quote-desk-agents.md).

Rule: ask for the narrowest permissions that work. When a tool's built-in login asks for more, record what it would reach and why it was not used.
