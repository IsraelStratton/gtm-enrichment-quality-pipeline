# Role cards: the quote desk's agents (chapter 5)

KB-137 A1.4: one card for each agent in chapter 5. Four agents took part in the comparison of three designs (B1); the eval kept the simplest that passed (B2), so only the **triage agent** runs in the n8n workflow. The other three stay in the engine and the eval as the comparison, with the same limits, and would get the same approval point if a later eval kept them.

Shared by all four: a single Claude Messages call each, with structured outputs; model `claude-haiku-5-5`, effort `low`; the playbook [`skins/quote-desk/quote-desk-playbook/SKILL.md`](../../../skins/quote-desk/quote-desk-playbook/SKILL.md), version 1.0.0, read on every run, with its name, version and SHA-256 logged on every triage; the guard rails fixed in [`engine/quotes.js`](../../../engine/quotes.js), outside the playbook (the quote goes in as escaped JSON data; code works out every figure and rule the figures break before any agent runs; a quote with a `fix` rule cannot be approved by anyone; the customer draft is checked in code; a screen looks for instructions in the rep note and special terms). Named owner of all four: the deal desk lead, a made-up role in this build; at an employer, deal desk or revenue operations, with finance owning the discount bands and legal the legal terms. Spend limit: the Claude Console workspace `gtm-pipeline`, US$10 a month. Review date: 07/12/2026, at the end of the build, or sooner if the eval bar is missed or the playbook changes a rule.
